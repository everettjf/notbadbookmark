Privacy policy

NotBadBookmark · Chrome extension

Effective date and scope

September 24, 2026. This policy describes NotBadBookmark version 1.1.0 and later, including version 1.1.1.

Information collection

NotBadBookmark has no account, analytics, advertising, or developer-operated backend. The extension does not send bookmark titles, URLs, tags, or recovery snapshots to our servers. Website icons use local placeholders; these versions do not request Google's favicon service.

Bookmarks and browser synchronization

Bookmarks are read and written through Chrome’s native bookmark store. Chrome may synchronize those bookmarks according to your browser and account settings. This is separate from NotBadBookmark’s local metadata.

Local storage and retention

  • Tags are stored in the extension’s IndexedDB database.
  • UI preferences, deletion recovery snapshots (including bookmark titles, URLs, folder structure, and tags), and recent import reports are stored in chrome.storage.local. The extension does not synchronize this metadata.
  • Import reports retain the latest 20 operations. Recovery snapshots remain local until extension data is removed.
  • Export an independent JSON backup before clearing extension data or uninstalling. Removing extension data is separate from deleting bookmarks in Chrome.

Actions you control

  • Import reads a file you choose and adds its bookmarks to Chrome.
  • Export writes a file to your device. JSON backups include tags and folder structure. You decide whether and where to share exported files.
  • Opening a bookmark navigates to that website, whose own privacy policy applies.
  • Copying a link writes it to your system clipboard.

Permissions

The extension does not request host permissions or scan website contents.

  • bookmarks: read, create, edit, move, and remove bookmarks and folders at your request.
  • storage: save preferences, local recovery snapshots, and import reports.

Recovery limitations

Recovery depends on local storage being available and cannot restore original Chrome IDs or native creation dates. Local recovery is not a substitute for an independent exported backup.

Contact

For product or privacy questions, email xnuapp@gmail.com. Do not attach a personal bookmark backup to a public issue.
