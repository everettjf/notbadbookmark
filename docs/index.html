Get up and running

Install straight from the Chrome Web Store — or build it yourself from source.

🧩 Add to Chrome

Prefer to build it yourself? Clone the repo and load it unpacked:

# Clone, install, and build
git clone https://github.com/everettjf/NotBadBookmark.git
cd NotBadBookmark
npm install && npm run build
1

Open extensions

Go to chrome://extensions/ in Chrome.

2

Enable Developer mode

Toggle it in the top-right corner.

3

Load unpacked

Select the NotBadBookmark project folder.

4

Open your bookmarks

Visit chrome://bookmarks — now it's NotBadBookmark ✨

🔒

Your data never leaves the browser

NotBadBookmark requests only the bookmarks and storage permissions. No host access, no network requests, no analytics — ever.
